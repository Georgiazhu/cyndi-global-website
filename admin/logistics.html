物流数据管理

产品编号作为查询键。保存后，公开查询页面会立即读取最新数据。物流节点和图片字段都写在同一份 JSON 中。

一次最多上传 20 张。上传成功后，图片地址会自动追加到当前 JSON 的 warehouseImages 数组。R2 未启用时，每张图片最大 1.5MB，图片单独保存到 D1，不会挤占物流字段。

可以继续增加客户、订单、SKU、箱规、报关、运输、仓库、联系人、单证和自定义字段。必填字段只有 productNo、productName；单条物流记录建议控制在 1.8MB 内。
